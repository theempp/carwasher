# Reference vault

House taste for cinematic scroll sites. **This file is the source of truth.**  
Do not keep inspiration reels in the repo. Do not re-open a source once it is ingested.

Client look (this job’s car, grade, copy) lives in `CLAUDE.md` + `docs/DESIGN_DIRECTION.md`.  
This vault is reusable recipes. Pull a few lines into the client look doc. Do not paste the whole vault into `CLAUDE.md`.

## How to use

Read this on every design pass. Designer names the **job**; the agent picks recipes/pieces. One film recipe unless two are justified. New reel → skill `reference-vault`. Do not re-open **Ingested**. Reply one line: what you used.

## Feel (one line)

One subject fills the frame. Scroll is the playhead. Chrome is an instrument, not a landing page.

## Overlay grammar

Quiet UI over a full-bleed film. Type is composed into the shot.

| Piece | Use | Do not |
|---|---|---|
| Huge wordmark | Beat 0, then it leaves | Sticky logo competing with the film |
| Playhead chrome | Thin bar / numeral tied to real progress | Fake “REC” that does not map |
| Process step | Same world; one line of copy | A new paid clip per step |
| Booking | Honest last frame + one action | Leftover Trust → Comparison → Booking |

Vertical only. One pin for the film. More story = honest stills and named sections below — not a second film.

## Page pieces (rebuilds)

Pick a few. Do not stack the whole table. Look docs still win.

| ID | Piece | Use when | Do not |
|---|---|---|---|
| `split-concept` | Type over a second material | One idea, two surfaces | Card grid of “features” |
| `compass-end` | Dark field, 2–3 journey links | Quiet close after a tour | Link farm footer |
| `type-object` | Editorial headline left, one still right | Story beat, not a catalog | Image+caption blog row |
| `hard-cta` | Sharp rectangle, one verb | One book action | Pill in the optical center |
| `frame-close` | Last cinematic frame as a surface | Still is honest | Labeling it “after / clean” |
| `shop-index` | Names as a list, sentence case, no prices | Copy the brief named | Tracked caps + hairline menu |
| `shop-rail` | Wordmark + few links + one hard book, after the pin | Page has a real book action | SaaS bar on the film |
| `rule-field` | Label + underline input | Short capture | Boxed SaaS inputs |
| `stone-field` | Full limestone (or charcoal) slab after the film | Estate / house jobs | Cream terracotta as a default |
| `sequence-slab` | Each signed film beat as its own type slab | Longer below-pin; beats already exist | Invented steps, fake numbers |

## Forbidden (from the refs)

- Live WebGL / Three / Spline as the hero
- Horizontal “Selected Work / DRAG →”
- SaaS cards, glass, gradient meshes
- Copying another brand’s page (VARNISH, Semler, Amali, O’Gara, Carlyle, KCS shop) as the site
- Sticky `% OFF` bars and Klaviyo popups
- Leftover Trust → Comparison → Booking landing
- Card grids, bounce, decorative parallax
